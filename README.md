# Черновик README — годовой проект (тема 14)

## Итоговая тема

**Сервис по конструированию портфеля и анализу активов** (рынок — Московская биржа, MOEX).

Сервис помогает инвестору собрать портфель акций под свой риск-профиль и горизонт, оценить риски входящих в него активов и проверить стратегию на исторических данных. Проект состоит из двух связанных блоков: конструирование портфеля и аналитика с прогнозированием.

Уровень: base/middle. План ниже — базовый, с запланированными расширениями до middle.

## Состав проекта

Каждый компонент разделён на три уровня: «Обязательно» — без этого не закрыть чекпойнты; «Опционально» — делаем, если хватает времени; «Middle» — при переходе на уровень middle. Расширение до middle бывает двух типов: **расширение** — новые методы в уже готовом модуле; **отдельная задача** — новый кусок работы со своим пайплайном.

| Компонент | Что делает |
| --- | --- |

### Сервис

Обязательно: FastAPI, PostgreSQL через ORM, Docker, деплой на VPS, тесты. Опционально: регулярное обновление данных с биржи.

## План работы

Даты после КТ1 ориентировочные. Пометка «middle» — выполняется при переходе на уровень middle. Пометка «опционально» — делаем, если хватает времени.

1. **КТ1. Старт и планирование — 6 октября.** Тема, команда, куратор, план; репозиторий и его каркас.
2. **КТ2. Сбор данных и EDA — 27 октября.**
   - Котировки, дивиденды и ключевая ставка через ISS API Московской биржи; версионирование данных через DVC.
   - EDA: доходности, волатильность, корреляции, дивиденды, кризисы 2020 и 2022.
   - Схема валидации для временных рядов.
3. **КТ3. Первые ML-модели — 27 ноября.**
   - Метрики: Sharpe, Sortino, максимальная просадка, MAE/RMSE.
   - Прогноз портфеля и размера дивидендов: наивные модели, ETS/SARIMA, линейная регрессия с регуляризацией. Базовые методы сборки портфеля, торговые правила.
   - Первая версия бэктеста, подбор гиперпараметров. Опционально: бустинг, GARCH, риск сокращения дивидендов через логистическую регрессию.
4. **КТ4. ML-сервис — 15 декабря.** FastAPI, PostgreSQL, Docker, деплой на VPS, тесты. Также ДЗ по «Инструментам разработки».
5. **Промежуточная защита — 10–15 января.**
6. **КТ5. Улучшение моделей — 15 марта.**
   - Бустинг, случайный лес, отбор признаков, новые признаки; сравнение всех стратегий с IMOEX. Опционально: риск сокращения дивидендов (классификация, ROC-AUC, дисбаланс классов), дивидендный портфель.
   - Middle, расширения: Black-Litterman, факторные модели, робастная оптимизация, глобальные модели, ML-фильтр сигналов.
   - Middle, отдельная задача: определение режима рынка и смена стратегии.
7. **КТ6. Нейронные сети — 5 мая.**
   - Две архитектуры на выбор из LSTM, CNN, Transformer для прогноза портфеля, сравнение с ML-моделями. Опционально: Chronos и TimesFM без дообучения.
   - Middle, отдельная задача: прогнозы моделей как вход Black-Litterman.
8. **КТ7. Финальные доработки — ~10 июня.** MLflow, воспроизводимость, анализ ошибок, стресс-тесты на кризисных периодах.
9. **Итоговая защита — 13–20 июня.**

## Что не входит в проект

| Пункт | Причина |
| --- | --- |
| Внутридневная торговля | Нужны минутные данные, комиссии съедают доходность |
| Прогноз дефолтов облигаций | На MOEX слишком мало случаев для модели |
| Прогноз купонов | У большинства облигаций купоны известны заранее |
| Отдельная модель для рекомендации | Дублирует прогноз портфеля |
| Нейросети для дивидендов | Около тысячи наблюдений — бустинг справится лучше |
